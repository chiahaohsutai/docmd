# docmd

**docmd** is a lightweight PDF parser that uses multimodal large language models (like Llava) to convert PDFs into Markdown format. It was built as a learning project to explore building APIs with Node.js and Express, as I’m typically more comfortable with Python and FastAPI.

The app exposes a single endpoint that accepts a PDF, processes each page, and returns Markdown generated by Llava via the Ollama API.

### Requirements

- Node.js (v18+ recommended)
- Ollama installed locally and running with a multimodal model (e.g. llava)

## Local Installation

1. Clone the repository

```bash
git clone <repository-url>
cd docmd
```

2. Install dependencies

```bash
npm install
```

3. Run the development server

```bash
npm run dev
```

Or, for production:

```bash
npm run build
npm run start
```
